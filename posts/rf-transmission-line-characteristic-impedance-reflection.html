50Ω 선로의 의미와 impedance가 달라질 때 reflected wave가 필요한 이유를 경계조건에서 설명합니다.

앞선 글에서는 trace의 propagation delay와 phase difference를 무시할 수 없을 때 lumped model이 distributed model로 바뀌는 이유를 살펴봤습니다. 이번에는 그 선로 위에서 voltage와 current wave가 어떻게 이동하고, load에서 왜 반사가 생기는지 다룹니다.

flowchart LR source[Source] --> incident[Incident wave] incident --> line[Transmission line Z0] line --> boundary[Load boundary ZL] boundary --> load[Delivered wave] boundary --> reflected[Reflected wave] reflected --> source

1. Transmission Line은 두 도체와 Field의 구조다

Coaxial cable, microstrip, stripline과 coplanar waveguide의 모양은 다르지만 signal conductor와 return conductor 사이의 field를 따라 energy가 전파된다는 공통점이 있습니다. 신호선 하나만 떼어 놓은 것이 선로가 아니라, return path와 dielectric을 포함한 단면 전체가 propagation mode를 결정합니다.

선로의 매우 짧은 구간에는 단위 길이당 series resistance R', inductance L', shunt conductance G', capacitance C'가 있습니다. Geometry와 material이 이 네 값을 정하고, 이 값들이 다시 propagation과 impedance를 정합니다.

2. RLCG에서 Wave Equation이 나온다

짧은 구간에 Kirchhoff's laws를 적용하고 길이를 0으로 보내면 telegrapher's equations를 얻습니다.

dV/dx = -(R' + j omega L') I
dI/dx = -(G' + j omega C') V

여기서 voltage와 current는 시간뿐 아니라 위치의 함수입니다. 두 식을 결합하면 forward wave와 backward wave가 존재하는 wave equation이 됩니다.

gamma = alpha + j beta
gamma = sqrt[(R' + j omega L')(G' + j omega C')]

alpha는 attenuation constant, beta는 phase constant입니다. Lossless approximation에서는 R' = G' = 0으로 두어 원리를 단순화합니다.

3. Characteristic Impedance는 DC Resistance가 아니다

Characteristic impedance Z0는 무한히 긴 선로나 반사가 없는 진행파에서 voltage와 current의 비입니다.

Z0 = sqrt[(R' + j omega L') / (G' + j omega C')]

Lossless line: Z0 = sqrt(L' / C')
Forward wave:  Z0 = V+ / I+

Lossless 50Ω line의 copper DC resistance가 50Ω이라는 뜻은 아닙니다. 50Ω은 진행하는 wave의 voltage-current ratio입니다. 실제 lossy line에서는 Z0가 complex이고 frequency-dependent할 수 있습니다.

flowchart TB geometry[Trace and return geometry] --> lc[L prime and C prime] material[Conductor and dielectric loss] --> rg[R prime and G prime] lc --> z0[Characteristic impedance Z0] rg --> z0 z0 --> ratio[Traveling-wave V divided by I]

4. Load 경계에서 Reflected Wave가 필요한 이유

Lossless line에서 incident wave는 V+/I+ = Z0를 만족합니다. 그러나 load에서는 total voltage와 current가 V/I = ZL을 만족해야 합니다. ZL과 Z0가 다르면 incident wave 하나만으로 두 조건을 동시에 만족시킬 수 없습니다.

Load 경계에서 backward wave가 생기고, incident와 reflected wave의 합이 boundary condition을 맞춥니다.

Gamma_L = V- / V+ = (ZL - Z0) / (ZL + Z0)
flowchart TB incident[Incident wave requires V plus over I plus equals Z0] --> boundary[Load requires total V over I equals ZL] boundary -->|ZL equals Z0| match[Gamma equals zero] boundary -->|ZL differs from Z0| reflected[Reflected wave supplies boundary condition]

5. Open과 Short는 같은 크기, 다른 Phase로 반사한다

LoadReflection coefficientLoad의 total voltage/current
ZL = Z0Gamma = 0반사 없음
OpenGamma = +1Voltage가 더해지고 current는 0
ShortGamma = -1Voltage가 상쇄되고 current가 더해짐

Open과 short는 이상적인 lossless reference에서 모두 전부 반사해 |Gamma| = 1입니다. 차이는 reflected voltage의 phase입니다. Open은 같은 phase, short는 180° 반대 phase로 돌아옵니다.

6. Reflected Power, Return Loss, VSWR

실수인 reference impedance를 사용하는 lossless system에서는 reflected power ratio가 |Gamma|^2입니다. 예를 들어 |Gamma| = 0.1이면 reflected power는 incident power의 1%입니다.

Reflected power ratio = |Gamma|^2
Return loss = -20 log10 |Gamma|
VSWR = (1 + |Gamma|) / (1 - |Gamma|)

Return loss는 양수로 표현할 때 클수록 좋고, S11(dB) = 20 log10|Gamma|는 음수로 표현해 더 작은 값일수록 좋습니다. 같은 상태를 부호가 다른 두 관례로 표현하므로 혼동하지 않아야 합니다.

7. Incident Wave와 Reflected Wave가 Standing Wave를 만든다

반사파가 입사파와 겹치면 위치에 따라 constructive와 destructive interference가 반복됩니다. Voltage maximum과 minimum이 공간에 고정되어 보이는 standing wave가 생깁니다.

flowchart LR forward[Forward wave] --> sum[Superposition] backward[Backward wave] --> sum sum --> maxima[Voltage maxima] sum --> minima[Voltage minima] maxima --> pattern[Standing-wave pattern] minima --> pattern

Line loss가 없다면 voltage maximum과 minimum의 비가 VSWR입니다. 실제 lossy line에서는 wave가 이동하며 감쇠하므로 위치에 따라 reflection magnitude와 standing-wave envelope도 달라집니다.

8. 같은 Load도 관찰 위치에 따라 다르게 보인다

Load에서 길이 l만큼 떨어진 지점의 input impedance는 lossless line에서 다음과 같습니다.

Zin = Z0 (ZL + j Z0 tan(beta l))
          / (Z0 + j ZL tan(beta l))

ZL은 고정되어 있어도 line length와 frequency가 바뀌면 beta l이 달라져 source에서 보이는 Zin도 변합니다. Characteristic impedance는 선로 단면의 속성이고, input impedance는 termination과 electrical length까지 포함한 관찰 결과입니다.

flowchart TB cross[Line cross section] --> z0[Z0] load[Load ZL] --> zin[Input impedance Zin] length[Electrical length beta l] --> zin z0 --> zin

9. Quarter-Wave Line은 Impedance Inverter다

Lossless line의 길이가 설계 frequency에서 정확히 lambda/4이고 load가 유한할 때 input impedance는 다음처럼 단순해집니다.

Zin = Z0^2 / ZL

그래서 open은 short처럼, short는 open처럼 보입니다. 서로 다른 두 실수 impedance Z1과 Z2를 설계 frequency에서 맞추려면 quarter-wave section의 impedance를 Zt = sqrt(Z1 Z2)로 선택할 수 있습니다.

이 변환은 frequency-selective합니다. Frequency가 바뀌면 section이 더 이상 90°가 아니므로 broadband match가 자동으로 유지되지 않습니다.

10. Stub은 Open과 Short를 Reactive Element로 바꾼다

끝이 open 또는 short인 line 조각도 관찰 위치에서는 frequency-dependent reactance로 보입니다. 적절한 길이의 stub을 main line에 연결하면 unwanted susceptance를 상쇄하거나 filter와 resonator를 만들 수 있습니다.

flowchart LR termination[Open or short termination] --> length[Electrical length] length --> reactance[Input reactance] reactance --> match[Matching] reactance --> filter[Filtering and resonance]

반대로 의도하지 않은 connector lead나 via stub도 같은 원리로 resonance와 insertion-loss notch를 만들 수 있습니다. Distributed element는 설계하면 기능이고 방치하면 discontinuity입니다.

11. 식이 성립하는 조건과 실제 손실

지금까지의 간단한 식은 uniform, single-mode, lossless 또는 low-loss line과 sinusoidal steady state를 중심으로 설명했습니다. 실제 PCB에서는 conductor loss, dielectric loss, dispersion, radiation, surface roughness와 mode conversion이 추가됩니다.

|Gamma|^2를 곧바로 power ratio로 해석하는 것도 real reference impedance를 전제로 합니다. Complex reference impedance나 lossy multiport에서는 voltage wave 대신 power-wave definition과 calibration plane을 분명히 해야 합니다. VNA 측정값도 cable과 fixture를 포함하므로 calibration과 de-embedding 위치가 중요합니다.

12. 정리: Reflection은 경계조건의 결과다

Gamma

다음 글에서는 이 reflection을 줄이기 위해 왜 RF 생태계가 50Ω을 기준으로 삼고, 실제 transistor의 complex impedance를 matching network와 Smith chart로 어떻게 다루는지 살펴보겠습니다.
