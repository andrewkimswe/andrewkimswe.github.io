앞선 글에서는 ZL과 Z0가 다르면 load의 경계조건을 만족시키기 위해 reflected wave가 생긴다는 것을 살펴봤습니다. 그렇다면 왜 RF cable과 장비는 50Ω을 반복해서 사용하고, 50Ω이 아닌 transistor는 어떻게 연결할까요?

flowchart LR source[50 ohm source interface] --> input[Input matching network] input --> device[Transistor complex impedance] device --> output[Output matching network] output --> load[50 ohm load interface]

1. 50Ω은 자연 상수가 아니라 Interface 표준이다

Signal generator, VNA, coaxial cable, connector와 RF module이 같은 reference impedance를 사용하면 서로 연결할 때마다 별도 변환을 만들 필요가 줄어듭니다. 대부분의 RF·microwave single-ended ecosystem은 50Ω을, cable TV와 video 계열은 75Ω을 많이 사용합니다.

“50Ω system”은 모든 내부 node가 50Ω resistor라는 뜻이 아닙니다. Cable의 characteristic impedance와 장비 port의 reference impedance가 50Ω이고, 외부 interface에서 reflection과 power wave를 이 기준으로 정의한다는 뜻입니다.

2. 50Ω은 Coax의 Loss와 Power Handling 사이에서 정착했다

Air-filled coaxial geometry를 이상화하면 attenuation이 가장 낮아지는 impedance는 약 77Ω 부근이고, breakdown-limited power handling은 약 30Ω 부근에서 유리합니다. 50Ω은 이 둘 사이의 실용적 절충으로 자리 잡은 뒤 장비와 connector 생태계의 표준이 되었습니다.

flowchart LR low[Near 30 ohm] --> power[Power-handling advantage] high[Near 77 ohm] --> loss[Low-attenuation advantage] power --> standard[50 ohm compromise and ecosystem] loss --> standard loss --> video[75 ohm cable and video systems]

이 수치는 coax의 conductor ratio와 dielectric 같은 가정에 의존합니다. 50Ω이 모든 transmission-line geometry의 보편적인 물리 최적점이라는 뜻은 아닙니다. 이미 구축된 component·measurement ecosystem과 호환된다는 이점이 오늘날에는 더 직접적입니다.

3. Transistor 내부까지 50Ω인 것은 아니다

GaN HEMT의 gate와 drain에서 최적 성능을 내는 impedance는 frequency, bias, drive level과 package parasitic에 따라 달라지며 보통 50 + j0 Ω가 아닙니다. 외부 connector가 50Ω이라는 이유로 die의 optimal load까지 50Ω으로 만들 필요는 없습니다.

flowchart TB external[External 50 ohm interface] --> network[Matching network] network --> internal[Device reference plane] internal --> target[Target complex source or load impedance] target --> metric[Gain, power, efficiency, noise or linearity]

Matching network는 external port에서 50Ω으로 보이게 하면서 device plane에는 설계 목표에 맞는 complex impedance를 제공합니다. 어느 reference plane에서 어떤 impedance를 말하는지 구분해야 합니다.

4. Matching은 Complex Impedance를 변환한다

Impedance는 resistance와 reactance의 합입니다.

Z = R + jX
Inductor: ZL = j omega L
Capacitor: ZC = 1 / (j omega C)

50Ω reference에서 load가 25 - j20 Ω이라면 matching network를 통과해 source 쪽에서 50 + j0 Ω으로 보이도록 resistance를 변환하고 reactance를 상쇄해야 합니다. Source가 complex라면 maximum available power의 조건은 일반적으로 conjugate match인 ZL = ZS*입니다.

저항을 직렬로 추가해 숫자만 50Ω으로 맞출 수도 있지만 real power를 heat로 버립니다. Low-loss matching에는 inductor, capacitor, transformer, transmission-line section과 stub 같은 reactive element를 사용합니다.

5. Reactive Network도 공짜는 아니다

이상적인 L과 C는 평균 real power를 소비하지 않지만 실제 부품에는 ESR, finite Q, parasitic과 self-resonance가 있습니다. Matching ratio가 크고 Q가 높아질수록 bandwidth가 좁아지고 component tolerance와 loss에 민감해질 수 있습니다.

flowchart TB ratio[Large impedance transformation] --> q[Higher loaded Q] q --> narrow[Narrower bandwidth] q --> sensitive[More tolerance sensitivity] real[Finite component Q] --> loss[Insertion loss and heat] parasitic[Package and layout parasitic] --> shift[Match frequency shifts]

“Reflection을 0으로 만든다”만으로 설계가 끝나지 않습니다. Bandwidth, insertion loss, voltage-current stress, harmonic termination과 manufacturability를 함께 확인해야 합니다.

6. Smith Chart는 Z를 Γ 평면에 옮긴 지도다

Smith chart는 complex impedance를 reflection-coefficient plane에 mapping한 도구입니다. 먼저 reference impedance Z0로 normalize합니다.

z = Z / Z0
Gamma = (z - 1) / (z + 1)
z = (1 + Gamma) / (1 - Gamma)

무한히 넓은 positive-resistance impedance plane이 |Gamma| ≤ 1인 원 안으로 들어옵니다. Constant-resistance circle과 constant-reactance arc가 그려져 있어 complex 계산과 matching 과정을 기하학적으로 읽을 수 있습니다.

7. Center, Open, Short와 위아래 절반 읽기

Left edgeShort, Z = 0Gamma = -1

위아래 해석은 impedance Smith chart 기준입니다. Admittance chart에서는 susceptance의 부호와 series·shunt 해석이 달라지므로 현재 보고 있는 grid를 확인해야 합니다.

flowchart TB chart[Impedance Smith chart] --> center[Center: matched reference] chart --> left[Left edge: short] chart --> right[Right edge: open] chart --> upper[Upper half: inductive] chart --> lower[Lower half: capacitive]

8. 한 점을 계산해 Smith Chart에 올려보기

50Ω system에서 ZL = 25 + j25 Ω를 생각해 보겠습니다.

z = (25 + j25) / 50 = 0.5 + j0.5
Gamma = (z - 1) / (z + 1) = -0.2 + j0.4
|Gamma| ≈ 0.447
S11 ≈ 20 log10(0.447) ≈ -7.0 dB

이 점은 resistance circle r = 0.5와 inductive reactance arc x = +0.5의 교점입니다. Center까지의 거리가 |Gamma|이고, center로 옮기는 것이 이 reference plane에서의 match입니다.

9. Series와 Shunt Element는 서로 다른 좌표에서 움직인다

Series inductor나 capacitor는 impedance에 jX를 더하므로 constant-resistance circle을 따라 이동합니다. Shunt element는 admittance Y = G + jB에 susceptance를 더하므로 admittance chart에서 보는 편이 자연스럽습니다.

flowchart LR load[Load impedance] --> series[Add series reactance in Z plane] load --> convert[Convert Z to Y] convert --> shunt[Add shunt susceptance in Y plane] series --> target[Move toward target impedance] shunt --> target

L-match는 series와 shunt reactive element 두 개를 조합해 reactance를 제거하면서 resistance level을 바꿉니다. 가능한 topology가 하나뿐인 것은 아니며 DC path, component value, low-pass 또는 high-pass 특성과 device bias 조건으로 선택합니다.

10. Transmission Line은 같은 |Γ| 원을 따라 움직인다

Uniform lossless line을 따라 reference plane을 이동하면 |Gamma|는 유지되고 phase만 변합니다. Smith chart에서는 center를 기준으로 같은-radius circle 위를 회전하는 것으로 보입니다. Rotation direction은 load 쪽인지 generator 쪽인지에 따라 달라집니다.

Lossy line에서는 이동할수록 reflected wave가 감쇠하므로 radius도 변합니다. Open·short stub이나 quarter-wave transformer를 chart에서 다룰 때는 line impedance, electrical length, loss와 design frequency를 함께 지정해야 합니다.

11. S11은 Reference Plane과 Termination을 포함한다

VNA의 S11은 port 1로 보낸 incident power wave에 대한 reflected power wave의 complex ratio입니다. 동일한 real reference impedance를 쓰고 다른 port가 그 reference로 terminate된 일반적인 조건에서는 input reflection coefficient와 직접 연결됩니다.

S11(dB) = 20 log10 |S11|
S11 = -20 dB  means  |S11| = 0.1
Reflected power ratio = 1%

측정 결과는 calibration reference plane부터 DUT까지의 cable, fixture와 transition 영향을 포함할 수 있습니다. Calibration과 de-embedding 없이 Smith chart의 한 점을 곧바로 die impedance라고 해석하면 안 됩니다.

12. PA의 목표는 단순한 50Ω Match보다 넓다

Small-signal amplifier에서는 gain, stability와 noise figure를 고려해 source·load match를 선택합니다. Power amplifier는 compression 영역에서 동작하므로 maximum output power, power-added efficiency, linearity와 ruggedness를 목표로 fundamental과 harmonic impedance를 함께 봅니다.

flowchart TB pa[Nonlinear PA at chosen bias and drive] --> pull[Source-pull and load-pull] pull --> contours[Gain, Pout, PAE and linearity contours] contours --> optimum[Choose target impedance] optimum --> network[Design matching network] network --> interface[Transform to external 50 ohm port]

Load-pull은 DUT에 제시하는 impedance를 바꾸며 성능 contour를 측정합니다. Maximum Pout 지점과 maximum PAE 지점이 다를 수 있으므로 “transistor output을 50Ω에 conjugate match하면 끝”이라고 단순화할 수 없습니다. Large-signal PA의 optimal load는 작은 신호의 S22만으로 결정되지 않습니다.

13. 정리: 50Ω은 출발점이고 성능 목표는 별도로 정한다

50Ω
장비·cable·module을 연결하기 위한 대표 reference impedance입니다.
Matching
한 reference plane의 complex impedance를 다른 plane에서 원하는 값으로 변환합니다.
Smith Chart
Normalized impedance와 reflection coefficient를 한 원 안에서 연결합니다.
S11
지정된 reference plane과 termination 조건에서의 input reflection입니다.
PA Design
50Ω interface 안쪽에서는 load-pull로 성능 목표에 맞는 impedance를 선택합니다.
flowchart TB standard[50 ohm ecosystem] --> reference[Known reference planes] device[Frequency and bias dependent device] --> target[Target source and load impedance] reference --> matching[Matching network] target --> matching matching --> verify[VNA, load-pull and power measurement]

결국 Smith chart의 목적은 모든 점을 기계적으로 50Ω에 만드는 것이 아닙니다. 어느 plane에서 어떤 impedance가 필요한지 정하고, 그 목표까지 이동하는 network를 설계하며, bandwidth와 loss를 포함해 측정으로 확인하는 데 있습니다.
